# Local development preferences

- Only run `git commit`, push, create/publish releases, or upload release assets when the user explicitly requests that action for the current work. Prior release authorization does not extend to later development requests. Keep ordinary development changes uncommitted and local.
- Do not reboot connected devices unless the user explicitly authorizes a reboot.
- Concealment is experimental. Preserve ordinary application behavior, use precise rules, and document unverified paths rather than claiming all detectors pass.
